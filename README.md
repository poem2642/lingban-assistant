## ✨ 特性

- **AI 对话**：基于 DeepSeek 的真实智能对话，上下文连续，记忆持久化。
- **记忆系统**：轻松说“以后回复简洁一点”，助手永远记住你的偏好。
- **社交助手**：粘贴收到的消息，一键生成 **简洁 / 友好 / 专业** 三种风格的回复，一键复制。
- **对话管理**：长按消息即可删除，操作直觉，界面清爽。
- **极简 UI**：纯白背景 + 圆角气泡 + 苹果蓝点缀，干净得像艺术品。
- **本地优先**：聊天记录和偏好全部本地存储，不上传服务器，隐私安心。

## 🧱 技术栈

- **语言**：Kotlin
- **UI**：XML + Material Design 3 主题
- **架构**：MVVM（部分）
- **本地数据库**：Room
- **网络**：OkHttp
- **AI 服务**：DeepSeek API（兼容 OpenAI 格式）
